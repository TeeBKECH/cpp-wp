# План: импорт банка вопросов квиза из Excel в CPT quiz

## Источник данных

- Файл в корне репозитория: книга Excel с именем на русском про группы тестов охранников и обычную нумерацию, расширение xlsx. Открывать только через дерево файлов проекта, без предпросмотра по клику из Markdown.
- Лист в книге: Банк вопросов.
- Строка 1 на листе: служебный заголовок банка — пропускаем при парсинге.
- Строка 2: имена столбцов.
- Строка 3 и дальше: строки вопросов.

## Столбцы Excel и поля WordPress

Столбец «Номер вопроса» (первая колонка в образце): для post_title и отладки.

Столбец «Вопрос»: в post_content (основной текст вопроса на сайте).

Столбцы «Ответ 1», «Ответ 2», «Ответ 3»: три строки репитера quiz_answers, подполе answer_text.

Столбец «Правильный вариант»: значения 1, 2 или 3 — это номер верного варианта, счёт с единицы. У одной строки репитера подполе is_correct включаем.

Столбец «Правильный ответ»: дубликат текста; можно не использовать, если логика только от «Правильный вариант».

Остальные столбцы Блок, Применимость и т.д.: по желанию сохранять в post_meta позже.

SCF: поле cpp_quiz_multiple выключено (false).

## post_title

Формат: номер из столбца «Номер вопроса», точка, пробел, затем текст из столбца «Вопрос».

Пример первой строки: номер 1 и текст про меры принуждения частных охранников.

Пример второй строки: номер 2 и текст про виды специальных средств.

Номер из Excel приводить к целому без дробной части. Если заголовок слишком длинный для БД — обрезать с многоточием; полный текст остаётся в post_content.

## post_content

Только текст из столбца «Вопрос». Если это простая строка без разметки — при сохранении обернуть в безопасный параграф или прогнать через санитайзер WordPress для контента.

## Репитер quiz_answers

Три элемента. Индекс правильного ответа от столбца «Правильный вариант» трактовать как один-два-три по порядку ответов.

## Очередь на странице QUIZ

Поле quiz_items на странице с шаблоном QUIZ заполняется отдельно: вручную в админке или вторым шагом скрипта с указанием ID страницы и списка ID созданных записей quiz в нужном порядке.

## Как запускать импорт

Экспорт листа в CSV UTF-8 или чтение xlsx через Python с библиотекой openpyxl.

На сервере WordPress: команда WP-CLI eval-file с PHP-скриптом, который вызывает wp_insert_post для типа quiz и update_field для полей SCF.

## Идемпотентность

Сохранять в метаполе номер строки источника или хеш строки, чтобы повторный запуск не создавал дубликаты.
