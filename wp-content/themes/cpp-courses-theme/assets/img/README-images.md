# Изображения для вёрстки

Файлы класть в `src/assets/img/`. Часть уже скопирована из `figma/images/` при экспорте.

| Файл                                            | Где используется                                           |
| ----------------------------------------------- | ---------------------------------------------------------- |
| `logo.svg`                                      | Шапка: логотип ЦПП                                         |
| `glavnyj-ekran.png`                             | Главная: фон блока «Главный экран» (интро)                 |
| `about-building.png`                            | Блок «О нас»: фото здания (главная, single, services, org) |
| `icons/course-icon-1.svg` … `course-icon-9.svg` | Карточки курсов на главной                                 |
| `icons/download-icon.svg`                       | Секция «Приказы»: иконка скачивания                        |
| `teachers/image-119.png` … `image-122.png`      | Карточки преподавателей (главная, single, services)        |
| `blog/image-125.png` … `image-127.png`          | Превью статей (главная, articles)                          |
| `partners/logo-1.svg` … `logo-5.svg`            | Секция «Наши партнёры» (при наличии файлов)                |

Опционально (если появятся в макете):

- `about-building.jpg` — блок «О нас»: фото здания (правая колонка)
- `teachers/photo-1.jpg` … `photo-4.jpg` — карточки преподавателей
- `blog/article-1.jpg` … — превью статей в сетке

В Pug пути к картинкам: `assets/img/имя.расширение` (от корня сборки).
В SCSS: `$img: '@/assets/img'`, затем `url('#{$img}/имя.расширение')`.

Если кладёте растр (PNG/WebP) вместо SVG — имя оставьте тем же, расширение в коде можно поменять (например `logo-1.png` → в pug указать `logo-1.png`).

**SVG-иконки из Figma:** если в макете иконка — Frame/Component с «icon» в имени (например `Course-icon-1`), скрипт `node figma-export.js` выгрузит её в `figma/images/` как `course-icon-1.svg`. Скопируйте нужные .svg в `src/assets/img/` (или в подпапку, например `icons/`) и подключайте в карточках по имени файла.
